# User docs

These docs are for scientists and operators using the IvoryOS browser UI. They focus on no-code operation after an integrator has launched a platform.

Start with [Using the UI](using-the-ui.md) for a tour of the main screen, then read the page for the area you are working in: [Instruments](instruments.md), the [Workflow designer](workflow-designer.md), [Execution](execution.md), [Data](data.md) and the [Library](library.md). Use [Run behavior](run-behavior.md) for prep/script/cleanup phases, pause, stop, errors, and queue behavior. See [Workflow step warnings](deck-compatibility.md) when a step is marked with a red or yellow icon.
